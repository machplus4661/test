# bulut

Claude Code bulut oturumlarının çalışma alanı.

Bu depo başka uygulamalar tarafından da kullanıldığı için bulut oturumlarında
yapılan tüm çalışmalar yalnızca bu klasörün altında tutulur. Kök dizindeki
diğer dosyalara dokunulmaz.

## İçerik

- `muhammed/` – MakeMaker asistan karakterlerinin ilki için tam 3D model, animasyon
  ve ses düzeni. Diğer karakterler (Dilara, Nihal, İlbay, Hatice) aynı düzenden
  geçirilecek. Başlangıç: `muhammed/README.md`.
